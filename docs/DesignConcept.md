# SenLearn
## 命名故事
森是我妻子的名字，这个软件是她驱使我做的，刚好SenLearn有神乐/神了的谐音，所以就叫SenLearn了。
## 设计理念
SenLearn的设计理念是让学习变得更有趣、更高效。通过结合人工智能技术和个性化学习方法，SenLearn旨在为用户提供一个互动性强、内容丰富的学习平台。我们希望用户在使用SenLearn的过程中，不仅能够提升知识水平，还能享受到学习的乐趣，从而激发他们的学习兴趣和持续学习的动力。
## 核心功能
导入PDF或者照片，然后进行OCR识别，
识别后可以进行对应知识内容的交互增强，如支持点读、相关扩展、总结归纳、动画等提高趣味性，重点是点读发音和趣味性；
支持连续拍摄多张照片组成一本书，而且后续可以对本书继续增加拍摄，每张照片就是一页，支持对每页进行OCR识别TTS和交互增强；
## 技术
iOS/iPadOS原生开发，
Capacitor，
可按需使用SwiftUI、UIKit和Combine框架等，
OCR首推 Apple 自带的 Vision 框架，也可结合CoreML进行OCR识别和自然语言处理，
完全离线、中英 TTS，我建议先用 Kokoro 做基础版本，再用 Qwen3-TTS 验证声音复刻和情绪配音，
纯本地应用，无服务端，数据库采用SQLite进行本地存储，
如需手写绘画考虑 PencilKit，PDF 阅读和标注考虑 PDFKit
## 交互设计
简洁，有趣，易用，符合 iOS/iPadOS 的设计规范，支持触控操作和手写笔输入，提供个性化设置和主题选择。
### 已确认的 UI / UE 方向
- 主要面向儿童学习、家长陪伴。
- 默认「森间书桌」采用 A 的温暖森林视觉与 C 的大按钮交互，突出听单词、听整句、再听一次。
- 在「设置 → 外观主题」保留四种可切换主题：森间书桌（默认）、清透原生、探索乐园、月光共读。
- 所有主题共用同一套核心操作与布局，切换主题不改变教材原色、当前页码、选词、语速或播放状态；主题选择保存在本机。
- 家长辅助分栏、阅读聚焦和减少动态效果独立于主题，避免换主题时重置用户的阅读习惯。
- 原始四版概念稿保留于 `docs/ui-ux/`；融合方案与主题设置的交互原型位于 `docs/ui-ux/prototype/`，详细规则见 `docs/ui-ux/设计说明.md`。
