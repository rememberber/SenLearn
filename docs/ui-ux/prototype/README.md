# SenLearn 融合方案与主题设置原型

默认采用 A「森间书桌」的温暖视觉和 C「探索乐园」的三项大按钮交互。原型内的「设置 → 外观主题」可切换森间书桌、清透原生、探索乐园、月光共读。

## 查看

在项目根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000/docs/ui-ux/prototype/`。页面与插画均从本地加载，无第三方脚本、字体或图片依赖。

## 可操作范围

- 打开 / 关闭设置，即时切换四种主题并在本机保存。
- 恢复默认主题，保留其他阅读偏好。
- 点击英文单词、切换示例页、调整语速、重听和停止。
- 浏览器具备本机英文声音时试听；没有可用声音时显示明确提示。
- 使用系统减少动态效果偏好，或在设置中进一步减少动态效果。

这是一份可操作的设计原型，不包含真实 PDF / 照片导入、OCR、本地模型管理或生产版离线 TTS。浏览器声音与未来 iOS 本地语音引擎是不同实现。

## 已完成的检查

- JavaScript 语法检查通过。
- 浏览器逐一检查四种主题、恢复默认、刷新恢复主题与语速、减少动态效果独立保存。
- 第 2 页选中 `tiny` 后恢复默认主题，页码、选词、0.8× 语速与动画偏好保持不变。
- 检查 320px 窄屏，无横向溢出；设置对话框可滚动，Escape 关闭后焦点回到设置入口。
- 月光主题下教材底色仍为暖白；本机声音可用时点词进入真实播放状态。
- 原型仅持久化主题、语速与动画偏好；刷新后示例阅读位置会回到第 1 页。
- `preview-default.jpg` 和 `preview-settings.jpg` 是原型的实际浏览器截图。

## 设计保留与衔接

- 四张原始概念图与 `../review-board.html` 保留不变。
- 当前原型的主题只改变应用外观，不改变示例教材原色、当前页码、选词、语速或正在播放的内容。
- 家长分栏、聚焦阅读等后续布局能力独立于主题。
- 共用插画为 `../assets/forest-lesson.png`，由内置 ImageGen 生成；提示词位于同目录。
- 产品规则以 `../设计说明.md` 与 `../../DesignConcept.md` 为准。
